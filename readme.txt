GSM Slider: cinematic Elementor slider with video backgrounds, glass morphism, WooCommerce, dynamic posts, and animations.

== Description ==

GSM Slider for Elementor is a production-ready, Elementor-native slider widget built for modern WordPress websites. It helps you create engaging hero sections, promotional carousels, and rich storytelling sliders directly inside Elementor without extra builders or shortcode complexity. This Elementor slider plugin supports image slides, video backgrounds, and custom content while giving you precise design control for typography, spacing, overlays, and CTA buttons.

What makes it different is the balance between visual polish and practical workflow. You get cinematic effects, per-slide animations, glass morphism content boxes, dynamic posts integration, WooCommerce product slides, and optional thumbnail navigation in one unified widget. It is ideal for Elementor users, agencies, and freelancers who need a reliable WordPress slider that can adapt to landing pages, ecommerce showcases, and portfolio hero sections.

Performance is a core focus: plugin assets are loaded only when the widget is used on a page, helping keep frontend output efficient. If you are looking for a flexible hero slider Elementor solution that combines creative effects with editor-friendly controls, GSM Slider gives you professional results with minimal setup.

= Key Features =
* Elementor-native slider widget with a clean editing experience

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/gsm-slider/` (or your chosen directory name)
2. Activate the plugin through the Plugins menu in WordPress
3. Edit any page with Elementor
4. Search for "GSM Slider" in the widget panel
5. Drag the widget to your page and add slides

== Frequently Asked Questions ==

= Does this work without Elementor? =
No. GSM Slider is built specifically for Elementor and requires Elementor to be installed and active.

= Is it compatible with Elementor Free (not Pro)? =
Yes. The plugin works with Elementor Free. Elementor Pro is not required.

= Will it slow down my website? =
No. CSS and JS are registered and loaded only when the GSM Slider widget is present on the page.

= Can I use YouTube or Vimeo videos as slide backgrounds? =
Yes. You can use embedded video URLs (YouTube/Vimeo) or self-hosted MP4 video files per slide.

= Is WooCommerce required? =
No. WooCommerce is optional and only needed if you want to build product-based sliders.

= Is the plugin translation ready? =
Yes. The plugin uses WordPress i18n functions and includes a translation template file (`gsm-slider.pot`).
